## About ADRs

ADRs document significant architectural decisions, capturing the context, alternatives considered, and consequences. They answer the question future developers will ask: "Why did they do it this way?"

### When to Create an ADR

Create an ADR when 3+ of these are true:
- Hard/expensive to reverse (one-way door)
- Alternatives were evaluated with trade-offs
- Affects future architectural decisions
- Future developers will wonder "why?"
- Not covered by existing guidelines
